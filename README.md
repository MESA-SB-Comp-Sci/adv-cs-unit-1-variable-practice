# Variable Practice

## Directions

-  Create a new codespace
-  open your index.js file 

--- 

## In your js file: 

- You will need to initialize variables depending on the scenario given in the comments 
  - Each variable written must contain the correct keyword for the scenario and the correct data type
  - You will need to write a comment with a rationale on why that keyword was chosen 
  - Check your work by using `console.log` on your variables to ensure correct initialization of variables

### Example: 

```js 
// TODO: Created a variable that holds a pet name

const petName = "Nina";

/*
* I used const because I do not intend to change my pet's name.
* The value is a string that holds the name of my pet, I used a string because it is the only data type that will hold a name as a value. 
*/

//Testing to see if our variable was created and what value it holds
console.log("The name of my pet is: ", petName);
```

## Code reminders: 

You can run the JS file by using the following code: 

```bash
node index.js
```

You will need to run the code every time you want to see a new change! 

You can write comments in the following ways:

```js
// This is a single line comment

/*
This a multi-line comment.
You might want to use this one instead for longer comments.
*/
```

### Criteria for success 
- Every variable is initialized with a value 
- Every variable follows JS camelCase conventions
- There is a comment with a rationale for every variable created
- There is a console.log that correctly logs the variables after creation
