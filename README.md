## In your js file: 

Copy the following prompts from the test and create your own variables in the code! 
Test to see if your variable was created by using `console.log(variableName)`.

Example: 
```js 
// Created a variable that holds a pet name

const petName = "Nina";

//Testing to see if our variable was created and what value it holds
console.log("The name of my pet is: ", petName);
```
